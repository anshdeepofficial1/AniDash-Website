# Private interface languages
Settings → Interface language. English (default), Hindi and Spanish. Translation uses bundled literals and localStorage only, with instant React updates and English fallback. No translation API, DOM scanning, telemetry, account syncing or third-party script is introduced. Anime titles, descriptions, user content, playback audio/subtitles, provider data and untranslated UI remain unchanged. Initial coverage: settings, main navigation, discover headings, search links, schedule, continue watching, and watch route states. Add explicit call sites and reviewed copy for additional screens.
