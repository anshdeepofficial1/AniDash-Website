# Web source manager (initial implementation)
The React frontend previously installed JSON manifests in localStorage without routing them to the player. Version 1 remains supported. Version 2 adds manga chapters (ordered HTTPS image URLs) and optional anime format mp4/hls. Install only media you are authorized to use. Imported sources are selectable on matching AniList media IDs, episode number and audio or manga chapter. Enable/disable/uninstall are local. No native APK, arbitrary repository JS/Dart, proxy, credentials, or automatic discovery is provided. Source selection makes a direct media request to the host; host sees network metadata and must support browser CORS and media access. Installed status does not imply availability. Existing built-in providers are unchanged. For native parity, create a separate reviewed adapter for each authorized provider with catalog, search, details, episode/chapter listing, stream/page resolution, timeouts and contract tests. Do not execute unreviewed code on the app origin.
